# cricketGame2
Ever played rock-paper-scissors but wished it had a cricket twist? That's exactly what this game is! Pick your cricket weapon of choice - bat, ball, or stumps - and try to outsmart the computer. We've kept it simple with big clickable buttons, plus you can keep track of your winning streak and look back at all your moves.
Features

Simple, intuitive gameplay
Real-time score tracking
Move history table
Local storage for persistent scoring
Reset functionality
Responsive design
Cricket-themed UI elements

Game Rules

The player selects one of three options:

Bat
Ball
Stump


The computer randomly selects one of the same three options.
Winner is determined by the following rules:

Bat beats Ball
Ball beats Stump
Stump beats Bat
Identical choices result in a tie



Technical Implementation

Built using HTML, CSS, and vanilla JavaScript
Uses localStorage for score persistence
Responsive layout using flexbox
No external dependencies required
